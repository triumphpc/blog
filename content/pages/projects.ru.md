## Open Source

| Проект | Описание |
|--------|----------|
| [taskflow](https://github.com/triumphpc/taskflow) | Одностраничный таск-менеджер (PWA) без зависимостей: приоритеты по Эйзенхауэру, повторяющиеся задачи, мастер планирования дня, синхронизация между устройствами через лёгкий Node-бэкенд и односторонний экспорт в Google Calendar. Без фреймворков и сборки. |
| [tagscope](https://github.com/triumphpc/tagscope) | Локальный git-браузер по тегам — показывает, какая версия сервиса развёрнута в каком окружении и насколько она отстала. |
| [kubescope](https://github.com/triumphpc/kubescope) | Локальный дашборд для Kubernetes в духе Lens в одном Go-бинарнике: быстрое переключение контекстов, обзор ресурсов, глобальный поиск, переменные окружения и логи подов в реальном времени. |
| [voice-typer](https://github.com/triumphpc/voice-typer) | Голосовой ввод по удержанию клавиши для macOS. Зажал Fn, сказал, отпустил — расшифровка локально через Whisper (MLX) и вставка в курсор. Полностью офлайн. |
| [blog](https://github.com/triumphpc/blog) | Этот блог — Hugo + PaperMod, автодеплой через GitHub Actions |
