## Open Source

| Project | Description |
|---------|-------------|
| [taskflow](https://github.com/triumphpc/taskflow) | Dependency-free single-page task manager (PWA) with Eisenhower priorities, recurring tasks, a daily planning wizard, cross-device sync over a tiny Node backend, and one-way Google Calendar export. No framework, no build step. |
| [tagscope](https://github.com/triumphpc/tagscope) | Local, tag-first git browser that shows which version of a service is on which environment — and how far behind it is. |
| [kubescope](https://github.com/triumphpc/kubescope) | A local, Lens-style Kubernetes dashboard in a single Go binary: fast context switching, resource browser, global search, pod env vars and live logs. |
| [voice-typer](https://github.com/triumphpc/voice-typer) | Push-to-talk voice typing for macOS. Hold Fn, speak, release — transcribed locally by Whisper (MLX) and pasted where your cursor is. 100% offline. |
| [blog](https://github.com/triumphpc/blog) | This blog — Hugo + PaperMod, auto-deployed via GitHub Actions |
